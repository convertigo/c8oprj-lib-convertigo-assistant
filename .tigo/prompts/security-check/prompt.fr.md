Effectue une revue de sécurité en lecture seule du projet Convertigo sélectionné. Commence par l'outil MCP Convertigo project-security-audit et les guides de sécurité/revue. Inspecte ensuite les objets sources pertinents par leur MCP propriétaire pour compléter l'analyse statique : accessibilité public/private/hidden des requestables, contextes authentifiés et autorisations, secrets ou références d'identifiants, chemins d'injection SQL et JavaScript, exposition HTTP et destinations sortantes, CORS, données personnelles dans les journaux.

Suis les entrées et les frontières de confiance ; un score statique ne prouve pas l'absence de risque. Hidden ne signifie ni authentifié ni privé. Sépare les constats confirmés, les hypothèses et les contrôles impossibles. Aucun test destructif, appel d'inférence ni test actif externe sans autorisation explicite. Ne recopie jamais une valeur secrète ou une donnée personnelle : cite l'objet/chemin et une description masquée.

Produis un rapport concis classé par gravité avec preuves/références, impact, proposition concrète de correction et limites de vérification pour chaque constat pertinent. Signale les risques acceptés et les questions ouvertes sans les masquer. Ne modifie ni code, droits, configuration ou données avant l'accord explicite de l'utilisateur sur les corrections proposées.
